# What is needed for an empirical study

The runnable demonstration is complete. A real crossing recommendation requires these records; none are currently supplied.

1. Confirm the study boundary, authority, crossing inventory and one feasible intervention package per crossing. Retain rejected candidates and reasons.
2. Collect the matched count windows in collection_protocol.md. Keep each observation date, duration, observer, weather and disruption note. Compute hourly rates before taking minimum, median and maximum. Do not treat repeated windows as independent sites.
3. Complete independent audits with photo IDs and component notes using audit_rubric.md. Preserve disagreement and document any central-rating adjudication. Verify applicable local requirements with the responsible reviewer.
4. For E1, define the walk-network catchment and document destinations, routes, alternative routes and the rating justification. The program needs E1 even when interpreting the base model because it runs the paired extension comparison.
5. Collate records into a copy of raw_observation_template.csv. Confirm identifiers match source forms. For multiple collection dates, use survey_date as the campaign completion date and preserve the full period in notes and the raw forms. Manually check that campaigns are comparable.
6. Run the field command in README.md. Inspect rejected rows, calculation traces, criterion correlations, all rankings and sensitivity tables. Field output labels do not certify observations.
7. Obtain an independent review without revealing model ranks first. Report disagreements and the sample selection rule. Complete the student contribution log with actual activities.

Do not substitute public traffic totals from a different road or period, invented counts, inferred photo ratings or arbitrary uncertainty percentages. The existing public-source register supplies literature and potential source leads, not observations near the campus.

## Independent review record

Use validation_review_template.csv. A review should include its evidence, scope and conclusion, not merely a numeric agreement score. Predefine the sampling rule before examining the ranking. Costs and engineering feasibility remain separate from the model's relative scores.
